# 上岸计划 2.0｜甘肃省考 / 国考学习中心

纯静态离线优先的刷题网站，可直接部署到 GitHub Pages，无需后端和 API Key。

## 核心功能

- **入门摸底**：40 分钟最多 30 道站内选择题，统一交卷查看解析。仅衡量内置/自行导入题的表现，不能当作官方行测模拟分数。
- **真实真题成绩记录**：线下完成完整真题后，手动记录试卷、年份、分数、用时、薄弱项；和站内练习完全分开。
- **分类训练**：10/20/40 道可选，优先未做题，答后看解析。
- **错题复习**、**收藏**：自动记录错误，复练正确后移出错题。
- **能力分析**：按科目统计首次正确率、题目总作答量和真题分数记录。
- **14 天计划**：任务勾选、手动完成跟踪。
- **25 分钟限时训练**：站内模拟练习，不等同于正式公考考试难度。
- **题库 JSON 导入**、**全站 JSON 备份恢复**。限时考试同一个浏览器标签刷新可以恢复进度。
- 自动读取旧版 v1 本地学习记录，保存为 v2 存储项。

## GitHub Pages 部署 / 升级

新用户：创建一个公开仓库（例如 `gansu-exam-quiz`），将本压缩包内 `index.html`、`app.js`、`questions.js`、`style.css`、`README.md` **直接上传仓库根目录**。进入 **Settings → Pages → Deploy from a branch → main → /(root) → Save**。

已有 v1 用户：在原仓库用这 5 个文件替换原有同名文件。**先在旧版中导出学习备份**。在同一个域名、浏览器上打开新版本，可自动迁移旧版浏览器数据；如果更换域名/浏览器，需要在新版本通过“数据中心”导入旧版备份。

发布后访问：`https://你的GitHub用户名.github.io/gansu-exam-quiz/`。Pages 地址以 GitHub 实际提示为准。

## 自己导入题库

打开网站 → 数据中心 → 下载题库格式示例。题目必须是以下 JSON **数组**：

```json
[
  {
    "id": "MY-0001",
    "c": "资料分析",
    "q": "示例：2+2等于多少？",
    "o": ["3", "4", "5", "6"],
    "a": 1,
    "e": "2+2=4。",
    "source": "自有题库"
  }
]
```

`id` 必须唯一且稳定；`a` 为正确选项索引（0=A，1=B，2=C，3=D）。导入时会校验字段和 ID。**题目 ID 对应到历史作答记录，替换原题时不要改变相同 ID 对应的正确答案和含义**。导入最多 2000 道/文件、5MB；大规模题库建议分批管理。浏览器本地存储容量有限，不适合无上限题库。

## 注意事项

- 内置 56 道题是原创**基础示例练习**，不是官方真题；也没有直接内置来源不明的考生回忆版、收费/版权题库。
- 不会自动从网上抓题；仅导入你拥有合法使用权的题目。网站不具备 AI 阅卷或申论作文评分能力。
- 真题分数由用户自行录入，不对真实性或难度进行核验。
- 学习记录仅存在当前浏览器 `localStorage`，限时答题中状态保存在 `sessionStorage`；GitHub Pages 不跨设备同步数据。清缓存/换设备前使用 JSON 备份。
- 考试资讯、岗位要求和报名时间应以当年官方公告为准。
